Прямой GET API для виджетов и касания задней панели iPhone:

1. Получить список проверок (GET):
/api/menu?username=...
2. Переключить статус (GET):
/api/toggle?id=[Выбранный элемент]&username=...
3. Создать новую проверку (GET):
/api/add?username=...&title=[Предоставленный ввод]
Как настроить команду на iPhone:
1. Действие «Получить содержимое URL» (ссылка 1)
2. Действие «Выбрать из списка»
3. «Если» [Выбранный элемент] содержит Добавить → «Запросить ввод» → «Получить содержимое URL» (ссылка 3)
4. «Иначе» → «Получить содержимое URL» (ссылка 2)
