Вы можете вызывать статус проверок или отмечать задачи двойным постукиванием по задней крышке iPhone через приложение Команды (Shortcuts).

1. Эндпоинт для входа:
POST /rest/v1/rpc/didido_login
2. Запрос задач текущего списка:
GET /rest/v1/didido_tasks?profile_id=eq...
3. Отметка задачи (Done):
PATCH /rest/v1/didido_tasks?id=eq.<TASK_ID>
