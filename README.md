# Didido — Это сделано?

Минималистичный личный веб-трекер повторяющихся бытовых проверок (выключен ли утюг, закрыта ли дверь, приняты ли витамины) с прямой интеграцией в **Apple Shortcuts & Back Tap** на iPhone.

![Didido Preview](public/preview.png)

## Особенности

- 🎯 **Быстрый фокус**: проверка выполненных и оставшихся дел на сегодня в один клик.
- 📱 **Apple Shortcuts & Back Tap**: вызов интерактивного меню по двойному касанию задней панели iPhone без открытия браузера.
- ⚡ **Headerless API**: простые прямые GET-ссылки для команд iOS без необходимости прописывать заголовки, bearer-токены или API-ключи.
- 🗄️ **Автономный бэкенд**: Node.js Serverless Functions на Vercel (`/api/*`) с базой данных PostgreSQL (Supabase).
- 🏷️ **Версионирование**: автоматическое отображение хэша коммита GitHub в интерфейсе приложения.

## API для Apple Shortcuts

Все эндпоинты работают через стандартные GET-запросы:

### 1. Получить список проверок
```text
GET https://didido.vercel.app/api/menu?username=ваш_логин
```
Возвращает список задач в чистом текстовом формате для действия «Выбрать из списка»:
```json
[
  "○ [ NO ] яндекс вендор",
  "✓ [YES] яндекс бизнес",
  "➕ Добавить новую проверку"
]
```

### 2. Переключить статус задачи
```text
GET https://didido.vercel.app/api/toggle?id=[Выбранный элемент]&username=ваш_логин
```
Принимает UUID задачи, название задачи или строку из меню (например, `○ [ NO ] яндекс бизнес`). Автоматически очищает префиксы и меняет статус `NO ↔ YES`.

### 3. Создать новую задачу
```text
GET https://didido.vercel.app/api/add?username=ваш_логин&title=[Текст задачи]
```

## Настройка команды на iPhone

1. Добавьте действие **«Получить содержимое URL»** &rarr; `https://didido.vercel.app/api/menu?username=ваш_логин` (GET).
2. Добавьте действие **«Выбрать из списка»** &rarr; входные данные из шага 1.
3. Добавьте блок **«Если»** `[Выбранный элемент]` содержит `Добавить`:
   - **«Запросить ввод»** (текст, вопрос: *"Что проверить?"*).
   - **«Получить содержимое URL»**: `https://didido.vercel.app/api/add?username=ваш_логин&title=[Предоставленный ввод]`
4. В блоке **«Иначе»**:
   - **«Получить содержимое URL»**: `https://didido.vercel.app/api/toggle?id=[Выбранный элемент]&username=ваш_логин`
5. Назначьте команду на **Касание задней панели** в *Настройки &rarr; Универсальный доступ &rarr; Касание &rarr; Касание задней панели*.

## Локальный запуск

1. Установите зависимости и создайте файл конфигурации:
```bash
npm run build
```

2. Запустите локальный сервер:
```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:3000`.

- **Бэкенд**: Node.js Serverless Functions (Vercel API Routes)
